Spotify

  1. Acesse developer.spotify.com/dashboard e faça login.
  2. Create app: nome livre; em Redirect URIs cole exatamente a URI acima (incluindo a / final); em “Which API/SDKs are you planning to use?” marque Web API; aceite os termos.
  3. Abra o app → Settings → copie o Client ID e cole acima. Não precisa de Client Secret (usamos PKCE).
  4. Se o app estiver em Development Mode e o dashboard tiver User Management, adicione o e-mail da sua conta Spotify.
  5. Clique em “Conectar Spotify”.
  6. Se você mover a pasta da extensão sem a chave fixa no manifest, o ID muda: atualize a Redirect URI no dashboard.
—

Para revogar o acesso no lado do Spotify: spotify.com/account/apps.
